# Инструкции для AI-ассистента

## Главное правило

**При любых структурных изменениях в проекте — обновляй файл `ARCHITECTURE.md` в корне репозитория.**

Под структурными изменениями понимается:
- Добавление / удаление / переименование файлов
- Новые функции в bash-модулях (do_*, menu_*)
- Изменение иерархии меню (добавление/удаление пунктов)
- Изменение структур данных Go (Config, Entry, Alert)
- Изменение потоков данных (новый шаг в pipeline, новый AI-провайдер)
- Добавление CLI-флагов в Go
- Новые поля в конфиге YAML
- Изменение дефолтных значений
- Новые глобальные переменные или пути

## Архитектура

Прочитай `ARCHITECTURE.md` перед началом работы. Там описано:
- Полная структура файлов
- **Bash**: все модули (00-05), все функции, иерархия меню
- **Go (VPN Guard)**: структуры данных, потоки, скоринг, AI chain
- Пути на сервере, зависимости, формат логов

## Конвенции кода

### Bash (src/*.sh)

- Функции: `do_*()` — действия, `menu_*()` — TUI-меню
- Цвета: `${CYAN}`, `${GREEN}`, `${RED}`, `${YELLOW}`, `${BLUE}`, `${BOLD}`, `${NC}`
- Вывод: `info()`, `success()`, `warn()`, `error()`, `header(title, parent)`
- Статусы: `get_docker_status(name)`, `get_bbr_status()` и т.д.
- Путь к VPN Guard конфигу: `$VPNGUARD_CONFIG` (из 00_globals.sh)
- Чтение YAML: `vpnguard_get_value "  key"` (с пробелами для вложенности)
- Запись YAML: `vpnguard_update_config_value "  key" "value"`

### Go (vpnguard/)

- Без внешних фреймворков (только fsnotify + yaml.v3)
- HTTP-клиенты: стандартный `net/http`, без SDK
- Типы баллов: `float64` (не int) — поддержка дробных весов
- Логирование: `log.Printf` с префиксом `vpnguard:`
- AI-анализ: всегда в горутине (`go processAlertAsync()`)
- AI-результат помечается тегом провайдера: `[Qwen] ...`, `[Gemini] ...`

## Синхронизация конфига

При добавлении нового поля в конфиг VPN Guard — обнови **три** файла:

1. `vpnguard/config/config.go` — struct + applyDefaults()
2. `vpnguard/vpnguard.yaml.example` — шаблон
3. `src/05_apps.sh` → `generate_vpnguard_config()` + `do_vpnguard_settings()` если нужна кнопка

## Чувствительные данные

**НЕ добавляй в код и НЕ коммить:**
- API-токены (Qwen JWT, Gemini API key, Telegram bot token)
- Файлы `.env`
- Папку `vpnguard/qwen/` (устаревшие Python-наработки с токенами)
- Любые vpnguard.yaml с реальными данными

Токены вводятся через скрипт при установке или через меню настроек.
